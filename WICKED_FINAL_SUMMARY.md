## �� Key Findings That Challenge Assumptions

### 1. "For Good" Beats "Defying Gravity"
**Conventional Wisdom:** Big, bombastic numbers win  
**Reality:** The emotional duet (58) beats the showstopper (56)  
**Takeaway:** Listeners prefer crying to their coffee over belting high notes

### 2. Song Duration Doesn't Matter
**Conventional Wisdom:** Keep it short for attention spans  
**Reality:** r=0.05, p=0.80 (zero correlation)  
**Takeaway:** "Dancing Through Life" (7.62 min) performs excellently  
**Quote:** "Stop cutting good art to fit arbitrary time limits"

### 3. Three Song Archetypes Exist
**Conventional Wisdom:** Songs are either hits or flops  
**Reality:** Epic Showstoppers, Narrative Builders, International Variants  
**Takeaway:** "Filler tracks" aren't filler—they're structural necessities

### 4. Consistent Quality Throughout
**Conventional Wisdom:** One-hit wonder albums dominate streaming  
**Reality:** Mean (46.9) ≈ Median (49.0), no extreme outliers  
**Takeaway:** This is an album with depth, not just singles

## 🛠️ Technical Components

### Data Collection
- Source: Spotify Web API
- Method: Python + spotipy library
- Output: `wicked_tracks_REAL.csv` (28 tracks)

### Statistical Analysis
- Language: Python 3.11
- Libraries: pandas, scipy, scikit-learn, numpy
- Tests: Pearson, ANOVA, t-test, K-means, PCA
- Output: `spotify_analysis_results.csv`

### Visualizations
- Tool: Plotly (interactive charts)
- Count: 6 visualizations
- Data source: `viz_data.json`
- All values traced to real Spotify data

### Portfolio Page
- Framework: Quarto
- File: `wicked-tiktok.qmd`
- Output: `wicked-tiktok.html`
- Features: Hero banner, stat cards, insight boxes, interactive charts
