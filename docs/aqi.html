    MCP + Letta Air Quality Intelligence Agent

    An intelligent agent system that combines the Model Context Protocol (MCP) with Letta AI to provide comprehensive air quality monitoring and personalized health recommendations.

    Overview

    This project demonstrates advanced AI agent architecture by integrating: - Letta AI for intelligent conversational agents - Model Context Protocol (MCP) for standardized data access - API Ninjas Air Quality API for real-time environmental data - Comprehensive health intelligence for activity-specific recommendations

    Key Features

    Real-Time Air Quality Monitoring

    • Live AQI data for cities worldwide
    • Detailed pollutant breakdown (PM2.5, PM10, O3, NO2, SO2, CO)
    • Historical trend analysis capabilities
    • GPS coordinate-based precise location tracking

    Intelligent Health Recommendations

    • Activity-Specific Advice: Tailored recommendations for jogging, cycling, walking, outdoor sports
    • Sensitive Group Protection: Special guidance for children, elderly, and people with respiratory conditions
    • Protective Measures: N95/P100 mask recommendations, air purifier usage, indoor alternatives
    • Optimal Timing: Best times for outdoor activities based on air quality patterns

    Multi-City Comparison

    • Side-by-side air quality analysis
    • Travel recommendations based on air quality
    • Pollution trend comparisons
    • Best/worst air quality insights

    Advanced MCP Integration

    • Standardized data access protocols
    • Extensible architecture for additional environmental data sources
    • Robust error handling and fallback mechanisms
    • Asynchronous data processing for optimal performance

    Technical Implementation

    Core Components

    1. AQIData Class

    @dataclass
class AQIData:
    location: str
    latitude: float
    longitude: float
    overall_aqi: int
    co_concentration: float
    no2_concentration: float
    o3_concentration: float
    so2_concentration: float
    pm2_5_concentration: float
    pm10_concentration: float
    timestamp: str

    2. MCP Server Integration

    • Asynchronous API calls for optimal performance
    • Geocoding integration for precise location mapping
    • Error handling with graceful degradation
    • Data validation ensuring reliable information

    3. Intelligent Agent Tools

    • current_aqi_tool: Real-time air quality data retrieval
    • aqi_comparison_tool: Multi-city comparative analysis
    • aqi_health_advice_tool: Personalized health recommendations

    Installation & Setup

    Prerequisites

    # Install required packages
pip install letta-client
pip install aiohttp
pip install mcp  # Model Context Protocol

# Optional: For enhanced functionality
pip install asyncio
pip install dataclasses

    API Configuration

    1. Get API Ninjas Key: Sign up at api.api-ninjas.com
    2. Set up Letta Server: Follow Letta installation guide
    3. Configure endpoints in the agent initialization

    Quick Start

    # Initialize the agent
aqi_agent = LettaAQIAgent(
    letta_base_url="http://localhost:8283",
    api_ninjas_key="your_api_key_here"
)

# Create and deploy
agent = aqi_agent.create_agent()

# Start interacting
response = aqi_agent.interact("What's the air quality in Dhaka?")

    Example Interactions

    Basic Air Quality Query

    User: "What's the air quality like in Dhaka right now?"

Agent: "Dhaka currently has an AQI of 189 (Unhealthy). The main concern is 
PM2.5 at 148 µg/m³. I recommend staying indoors and using air purifiers. 
If you must go outside, wear an N95 mask and limit exposure time."

    Activity-Specific Advice

    User: "I have asthma and want to go cycling in Seattle. Is it safe?"

Agent: "Seattle's current AQI is 76 (Moderate). For someone with asthma, I'd 
recommend postponing outdoor cycling. The O3 levels are elevated at 92 µg/m³. 
Consider indoor cycling or wait until evening when air quality typically improves."

    Multi-City Comparison

    User: "Compare air quality between Dhaka, Chittagong, and New York City"

Agent: "Here's the comparison:
• Dhaka: AQI 189 (Unhealthy) - Avoid all outdoor activities
• Chittagong: AQI 145 (Unhealthy for Sensitive Groups) - Limited outdoor time
• New York City: AQI 67 (Moderate) - Best option for outdoor activities

Recommendation: If traveling, New York City offers the cleanest air quality."
