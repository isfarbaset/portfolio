🌍 AIR QUALITY QUICK REPORT

🌍 Air Quality Intelligence

Real-time environmental monitoring with AI-powered health recommendations

Overview

An intelligent agent system combining the Model Context Protocol (MCP) with real-time air quality data to provide personalized health recommendations for outdoor activities. Built with Python, async architecture, and the API Ninjas Air Quality API.

🌍 Global Coverage

6 Pollutants Tracked

15min Update Frequency

⚡ Real-Time Data

Key Features

📊
Real-Time Monitoring

Live AQI data for cities worldwide with detailed pollutant breakdown (PM2.5, PM10, O3, NO2, SO2, CO)

💡
Smart Recommendations

Activity-specific advice for jogging, cycling, walking, and outdoor sports tailored to current conditions

🔍
Multi-City Compare

Side-by-side analysis of air quality across multiple cities for travel planning

🛡️
Health Protection

Special guidance for sensitive groups including children, elderly, and those with respiratory conditions

Core Components

1. AQI MCP Server (aqi_mcp_server.py) - Asynchronous API integration with aiohttp - Geocoding for city → GPS coordinate conversion - Real-time air quality data retrieval - Health category classification (Good, Moderate, Unhealthy, etc.) - Activity-specific recommendation engine

2. Interactive Demo (aqi_demo.py) - Two modes: Interactive and Quick Report - Multi-city comparison with rankings - Color-coded terminal output - Comprehensive error handling

3. Data Model (AQIData class)

@dataclass
class AQIData:
    location: str
    latitude: float
    longitude: float
    overall_aqi: int
    co_concentration: float
    no2_concentration: float
    o3_concentration: float
    so2_concentration: float
    pm2_5_concentration: float
    pm10_concentration: float
    timestamp: str

Installation & Quick Start

Prerequisites

pip install aiohttp

Get API Key

  1. Sign up at API Ninjas
  2. Get your free API key
  3. Set environment variable:
export API_NINJAS_KEY='your_key_here'

Run the Demo

# Quick Report
python3 aqi_demo.py quick

# Interactive Mode
python3 aqi_demo.py

Real-World Use Cases## Real-World Use Cases

1. Daily Health Management

Scenario: “Should I go jogging this morning?”

The system provides instant analysis: - Current AQI level for your location - Specific advice for jogging/running - Best time windows for outdoor exercise - Alternative indoor options if needed

Real Example (Dhaka, AQI 116): > “Sensitive individuals should reduce jogging duration or exercise indoors. Consider indoor cycling if you have respiratory conditions.”

2. Travel Planning

Scenario: “Which city has better air quality: Boston or Los Angeles?”

Multi-city comparison shows: - Boston: AQI 45 (Good) - Perfect for outdoor activities - Los Angeles: AQI 112 (Unhealthy for Sensitive Groups) - Limited outdoor time recommended

Decision: Boston offers significantly better conditions for travelers with respiratory concerns.

3. Family Safety

Scenario: “Is it safe to take my kids to the playground?”

Sensitive group guidance provides: - Real-time safety assessment - Protective measures if needed (masks, timing) - Alternative indoor activities - Hourly recommendations

🤖 Gen AI Conversational Agent (New!)

Building on the core MCP architecture, I’ve enhanced this project with AI-powered natural language understanding using OpenAI GPT. The Gen AI agent transforms raw air quality data into personalized, contextual health advice through natural conversations.

What Makes It Gen AI?

💬
Natural Language Understanding

Ask questions in plain English - no commands to memorize. The AI understands context and intent.

🎯
Personalized Recommendations

Tailored advice based on your health conditions, activities, and concerns (asthma, allergies, age, etc.)

🧠
Contextual Intelligence

Combines real-time data with medical knowledge, considers multiple factors for nuanced advice

🔄
Conversation Memory

Maintains context across multi-turn conversations for follow-up questions and clarifications

Live Gen AI Conversations

Example 1: Simple Air Quality Check

💬 User: What’s the air quality like in Boston today?

🤖 AI Assistant: Great news! The air quality in Boston is currently excellent with an AQI of 47, which falls in the “Good” category.

Here’s what this means for you: • Air is safe for everyone - All outdoor activities are perfectly fine • PM2.5: 0.7 µg/m³ (very low particulate matter) • Ozone: 56.3 µg/m³ (within safe limits)

This is ideal weather for outdoor activities! Whether you want to jog, cycle, or spend time in the park, the air quality won’t be a concern today. Enjoy the fresh air! 🌤️

What’s Different: Unlike the basic demo, the Gen AI agent provides empathetic, conversational responses that explain “why” and “what to do” - not just data dumps.

Example 2: Health-Specific Personalized Advice

💬 User: I have asthma. Can I go jogging in Dhaka today?

🤖 AI Assistant: I’d advise caution for jogging in Dhaka today. The current AQI is 116, which is in the “Unhealthy for Sensitive Groups” category.

Since you have asthma, here’s what I recommend:

⚠️ Today’s Conditions: • AQI: 116 (Unhealthy for Sensitive Groups) • PM2.5: 48.9 µg/m³ (elevated particulate matter) • PM10: 58.6 µg/m³ (elevated)

🏃 Jogging Recommendations: 1. Best option: Exercise indoors today (gym, treadmill, indoor track) 2. If you must jog outside: - Go early morning or late evening when AQI is typically better - Keep it short (15-20 minutes max) - Stay at a comfortable pace - avoid intense exertion - Carry your inhaler - Monitor how you feel - stop if you experience any symptoms

  1. Watch for symptoms: Coughing, wheezing, shortness of breath, or chest tightness mean you should stop immediately

📱 Better days ahead: Check the AQI forecast - it might improve in the next day or two. Your health comes first! 💙

Intelligence at Work: The AI understands the user has a pre-existing condition and provides: - Risk assessment specific to asthma - Tiered recommendations (best → acceptable) - Symptom monitoring guidance - Empathetic, safety-first messaging
