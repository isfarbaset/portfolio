🌍 AIR QUALITY QUICK REPORT

🌍 Air Quality Intelligence

Real-time environmental monitoring with AI-powered health recommendations

Overview

An intelligent agent system combining the Model Context Protocol (MCP) with real-time air quality data to provide personalized health recommendations for outdoor activities. Built with Python, async architecture, and the API Ninjas Air Quality API.

🌍 Global Coverage

6 Pollutants Tracked

15min Update Frequency

⚡ Real-Time Data

Key Features

📊
Real-Time Monitoring

Live AQI data for cities worldwide with detailed pollutant breakdown (PM2.5, PM10, O3, NO2, SO2, CO)

💡
Smart Recommendations

Activity-specific advice for jogging, cycling, walking, and outdoor sports tailored to current conditions

🔍
Multi-City Compare

Side-by-side analysis of air quality across multiple cities for travel planning

🛡️
Health Protection

Special guidance for sensitive groups including children, elderly, and those with respiratory conditions

Core Components

1. AQI MCP Server (aqi_mcp_server.py) - Asynchronous API integration with aiohttp - Geocoding for city → GPS coordinate conversion - Real-time air quality data retrieval - Health category classification (Good, Moderate, Unhealthy, etc.) - Activity-specific recommendation engine

2. Interactive Demo (aqi_demo.py) - Two modes: Interactive and Quick Report - Multi-city comparison with rankings - Color-coded terminal output - Comprehensive error handling

3. Data Model (AQIData class)

@dataclass
class AQIData:
    location: str
    latitude: float
    longitude: float

    co_concentration: float
    no2_concentration: float

    so2_concentration: float
    pm2_5_concentration: float
    pm10_concentration: float
    timestamp: str

Installation & Quick Start

Prerequisites

pip install aiohttp

Get API Key

  1. Sign up at API Ninjas
  2. Get your free API key
  3. Set environment variable:
export API_NINJAS_KEY='your_key_here'

Run the Demo

# Quick Report
python3 aqi_demo.py quick

# Interactive Mode
python3 aqi_demo.py

Real-World Use Cases## Real-World Use Cases

1. Daily Health Management

Scenario: “Should I go jogging this morning?”

The system provides instant analysis: - Current AQI level for your location - Specific advice for jogging/running - Best time windows for outdoor exercise - Alternative indoor options if needed

Real Example (Dhaka, AQI 116): > “Sensitive individuals should reduce jogging duration or exercise indoors. Consider indoor cycling if you have respiratory conditions.”

2. Travel Planning

Scenario: “Which city has better air quality: Boston or Los Angeles?”

Multi-city comparison shows: - Boston: AQI 45 (Good) - Perfect for outdoor activities - Los Angeles: AQI 112 (Unhealthy for Sensitive Groups) - Limited outdoor time recommended

Decision: Boston offers significantly better conditions for travelers with respiratory concerns.

3. Family Safety

Scenario: “Is it safe to take my kids to the playground?”

Sensitive group guidance provides: - Real-time safety assessment - Protective measures if needed (masks, timing) - Alternative indoor activities - Hourly recommendations

Health Category System

The system uses WHO/EPA guidelines to classify air quality:

Category AQI Range Indicator Meaning
🟢 Good 0-50 Excellent Safe for all activities
🟡 Moderate 51-100 Acceptable Generally safe, sensitive individuals may want to limit prolonged exertion
🟠 Unhealthy for Sensitive 101-150 Caution Sensitive groups should reduce outdoor activities
🔴 Unhealthy 151-200 Alert Everyone should limit outdoor exertion
🟣 Very Unhealthy 201-300 Warning Avoid all outdoor activities
⚫ Hazardous 301+ Emergency Health emergency - stay indoors

Error Handling & Reliability

The system includes comprehensive error handling:

  • API Fallbacks: Graceful degradation if API is unavailable
  • Data Validation: Input/output checking for data integrity
  • Geocoding Errors: Clear messaging for invalid city names
  • Network Issues: Retry logic with exponential backoff
  • Rate Limiting: Respects API limits and queues requests
