## Troubleshooting

### If page doesn't load:
1. Check GitHub Actions for build errors
2. Verify docs/wicked-tiktok.html exists in repository
3. Clear browser cache and retry
4. Wait 5 minutes for GitHub Pages cache to update

### If visualizations don't load:
1. Check browser console for JavaScript errors
2. Verify Plotly library is loading
3. Check data file paths in the HTML source

### If styling looks broken:
1. Verify style.css is in docs folder
2. Check CSS paths in HTML header
3. Clear browser cache
